# DeepSeek 对话成本计算器

一个**纯前端、离线可用**的单文件工具：上传自己的 DeepSeek 数据导出包（ZIP），在浏览器本地算出这些对话在 API 上等价多少钱。

打开即用，无需安装、无需联网、无需注册。

## 功能

- **拖入即算**：选择或拖入导出 ZIP，本地解析对话、工具调用与 token 用量
- **分时期计价**：内置 DeepSeek 历次模型价格与峰谷时段，按消息时间自动匹配单价
- **成本拆分**：模型输入 / 输出、网页搜索、网页抓取分别计费，给出明细与占比
- **4 套主题**：深海静谧 / 报刊纸本 / 瑞士极简 / 黑金年报，网页与海报同步换肤
- **1080×1440 海报**：实时预览，一键导出分享图
- **示例账单**：不想上传数据时，可一键预览演示效果（演示数据，非任何真实账户）
- **计算说明**：内置完整方法论、公式与误差边界，可一键复制 Markdown

## 隐私与安全

这是本工具的设计前提，不是附加说明：

| 项 | 实现 |
|---|---|
| 网络请求 | 零。`connect-src 'none'`，无任何 fetch / XHR / WebSocket / sendBeacon |
| 数据持久化 | 零。不使用 localStorage / cookie / IndexedDB |
| 动态执行 | 零。无 `eval` / `new Function` |
| 外部资源 | 零。单文件、无 CDN 依赖，断网可用 |
| 计算位置 | 全部在浏览器本地完成，导出包不会离开你的设备 |

正因如此，本仓库只发布这个工具本身——分析过程、中间数据与原始导出包均不在仓库内。

打开后点击「预览示例账单」先看效果，或拖入自己的导出 ZIP 开始计算；随后切换主题、查看明细、导出海报。

## 口径说明

结果为基于公开定价与推断规则的**估算**，非官方账单。缓存命中率、请求次数等无法从导出包直接反推的部分，已在工具内「计算说明」中标注为推断并给出误差区间。完整方法论见工具内说明页。
